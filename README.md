# justrans

[한국어](#한국어)

justrans is a browser extension for Chrome and Firefox that translates selected text and webpages, and summarizes webpage content and YouTube transcripts using a provider selected by the user.

## Features

- Translate selected text on the current webpage.
- Show immersive translations alongside webpage content.
- Summarize the current webpage or a YouTube transcript with a configured LLM provider.
- Choose providers, models, target languages, and custom prompts.

Translation and summary content is sent directly from the browser to the selected provider. It does not pass through a justrans-operated server. LLM features may require the user's own API key.

## 한국어

justrans는 사용자가 선택한 provider를 이용해 선택 텍스트와 웹페이지를 번역하고, 웹페이지 본문과 YouTube 자막을 요약하는 Chrome·Firefox 확장 프로그램입니다.

- 현재 웹페이지에서 선택한 텍스트 번역
- 원문과 번역문을 함께 보여주는 몰입형 웹페이지 번역
- 설정한 LLM provider를 이용한 현재 페이지 또는 YouTube 자막 요약
- 기능별 provider·model·대상 언어·사용자 prompt 설정

번역·요약 데이터는 브라우저에서 사용자가 선택한 provider로 직접 전송되며 justrans 운영자 서버를 거치지 않습니다. LLM 기능에는 사용자의 API key가 필요할 수 있습니다.

문의·버그 제보·데이터 삭제 지원 요청은 [GitHub Issues](https://github.com/pravusid/justrans/issues)에 남겨 주세요. issue에 API key 등 비밀정보를 넣지 마세요. 자세한 내용은 [개인정보 처리방침](./PRIVACY.ko.md)을 확인하세요.
